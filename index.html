Let's understand Python functions step by step. Think of a function as a labelled box: you put things in, something happens, and a result comes out.
📘 Explanation

A function is a named block of code you can run whenever you want. It takes parameters as input, does work, and optionally sends a value back with return. Defining it with def doesn't run it — calling it does.

💡 Example
def greet(name, greeting="Hello"):
    """Return a friendly greeting."""
    return f"{greeting}, {name}!"

message = greet("Learner")
print(message)  # Hello, Learner!
